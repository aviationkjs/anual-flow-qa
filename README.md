# 매뉴얼 흐름 Q&A

정비사가 매뉴얼 절차를 순서대로 보다가, 막히는 단계에 질문을 꽂으면 감독자가 우선순위대로 답하고, 승인된 답이 해당 단계에 보충설명으로 붙는 구조의 시제품입니다.

## 화면
- **챗봇**(오른쪽 아래): 등록된 매뉴얼 단계와 승인된 보충설명에서만 찾아 출처와 함께 답합니다. 못 찾으면 추측하지 않고 감독자 질문으로 넘깁니다.
- **3D 도면**: Step에 연결된 STL을 저장된 시점과 표시 핀으로 보여줍니다.
- **정비사**: 절차 흐름 보기, 단계/단계 사이에 질문(사진 첨부), "나도 궁금"
- **감독자**: 우선순위 질문 목록 → 답변(근거 매뉴얼 필수, 사진 첨부) → 흐름에 반영 승인 / 원문 참조 처리
- **관리**: 단계 편집, 단계별 사진 추가, JSON 내보내기/가져오기

## 우선순위 점수
안전단계(WARNING 40 / CAUTION 20) + 작업 중단 40 + "나도 궁금" 1명당 8(최대 40) + 대기 1시간당 1(최대 20)

## 예시 데이터
삼성 드럼세탁기 잔여물(배수) 필터 청소 절차를 원문 매뉴얼에서 요약했습니다. 그림은 예시용으로 새로 그렸고, 원문 매뉴얼은 앱 상단 링크에서 볼 수 있습니다.
감독자 보충설명은 참고용이며, 승인된 작업 기준은 매뉴얼 원문입니다.

## 저장 방식
데이터와 사진은 브라우저(localStorage)에 저장됩니다. 여러 사람이 함께 쓰려면 JSON으로 주고받거나, 이후 서버 저장 방식으로 확장이 필요합니다.

## 파일 구성
- `data/manual.json` 매뉴얼 Task·Step (관리 화면 [manual.json 내보내기]로 받은 파일로 덮어씀)
- `data/synonyms.json` 챗봇 동의어 사전 (예: 필터 캡 = 마개 = 뚜껑)
- `models/` STL 파일과 `models.json` (넣는 방법은 `models/README.md`)
- `vendor/three/` 3D 표시용 three.js (MIT 라이선스)

3D 도면과 데이터 파일은 GitHub Pages 주소로 열어야 동작합니다. 파일을 더블클릭해서 열면 3D가 표시되지 않습니다.
